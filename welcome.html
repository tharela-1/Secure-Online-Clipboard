Welcome to the Secure Online Clipboard website!

Here you can send the data from sender to the receiver in a very safe way. You can set the following details as well:
  1. Message to be sent
  2. Password to open the message
  3. For how much time the message should be accessible (max of 23 hours 59 minutes 59 seconds i.e., 23:59:59)
  4. Number of times you can read the message (max of 2049 times)
  5. Number of times you can enter wrong passwords (max of 100 times)

The choosing of the settings 4 and 5 is your choice. You can choose it if you need, otherwise you need not choose. If you enter the value as 0 there then the settings are not chosen (This is applicable only for the settings 4 and 5 mentioned above) i.e., For setting 4 if you enter the value as 0 then the setting 4 is not chosen and for the setting 5 if you enter the value as 0 then the setting 5 is not chosen.
