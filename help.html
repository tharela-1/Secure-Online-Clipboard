How to use this website?
  • Step - 1: Type the text that you need to send to the receiver
  • Step - 2: Type the password for the message
  • Step - 3: Set the Time To Live(TTL) value i.e., for how long the message should be accessible
    For example:
    1. If you need to set the time as 12 hours 31 minutes 58 seconds then enter the following values: 12 in the hours box 31 in the minutes box and 58 in the seconds box.
    2. If you need to set the time as 12 hours then enter the following values: 12 in the hours box and 0 in the minutes box and 0 in the seconds box
    3. If you need to set the time as 11 hours 45 minutes then enter the following values: 11 in the hours box 45 in the minutes box and 0 in the seconds box
    4. If you need to set the time as 11 hours 45 seconds then enter the following values: 11 in the hours box 0 in the minutes box and 45 in the seconds box
    5. If you need to set the time as 25 minutes 45 seconds then enter the following values: 0 in the hours box 25 in the minutes box and 45 in the seconds box
    6. If you need to set the time as 35 minutes then enter the following values: 0 in the hours box 35 in the minutes box and 0 in the seconds box
    7. If you need to set the time as 45 seconds then enter the following values: 0 in the hours box 0 in the minutes box and 45 in the seconds box
    If you set a TTL value of below 30 seconds i.e., below 0 hours 0 minutes 30 seconds then the TTL would be set to 30 seconds.
  • If you want to opt for the extra privacy features, you can do that as well by doing the following:
    • If you want to create a restriction to access the clipboard contents only for a specific number of times i.e., setting a read count limit then you can enter that value in the input field, If you dont want to set this, then enter 0.
    • If you want to delete the record in the database after specific number of wrong password attempts then enter that value in the input field. If you don't want to set this, then enter 0.
      NOTE: The count of wrong password attempts for each clipboard is done cumulatively i.e., From the creation of the clipboard, till its deletion how many wrong password attempts have been made. It is not the count of continuous wrong password attempts.
      For example: Let's take C means user has entered the correct password and W means user has entered the wrong password.
      Then if the accessing order is W W C W W W C, it is counted as 5 wrong password attempts.
  • Step - 4: Set the maximum limit for updation. If you set 0, the clipboard is read-only. If you set a value greater than 0 then the number of updations can be done for the maximum number of times that you set before the clipboard gets deleted.
  • Step - 5: Press the Send Text button
  • Step - 6: Note down the clipboard code (clipboard ID) generated and password that you have entered, because those data are very important for retrieval of text.
  • Step - 7: To retrieve the text, enter the clipboard ID and the password and press the Retrieve Text button.
  • Step - 8: You will see the retrieved text in the text area.
  • Step - 9: If you want to update the clipboard's content, enter the text in the updated text field and press the Update Text button.
Points to note:
  • To reset the form you an press the reset button in the respective section to reset that particular section.
  • If the clipboard ID or password is lost, there is no way of retrieving that.
  • You can send feedback to the developer by clicking the Send Feedback button in the Home Page. It would take you to the Feedback page where you can enter the feedback.
  • Ensure that you have filled all the required fields in the Section - I and Section - II of the Sender Section before you press the Send Text button.
  • If you press the Show Password button then the text of the button changes from Show Password to See Now and you can see the password that you have typed for 5.5 seconds. During the view time, you can't edit the password that you have entered in the password field. After that the text of the button changes back to Show Password. Then you can edit the password that you have entered in the password field. When the text of the button in the sender section's password field has the text Show Password at that time you can type / edit the password entered in the password field in the sender section. When the text of the button in the sender section's password field is See Now, you can't edit the password that you have entered in the password field in the sender section. Similar concept applies for the receiver section's password field as well.
  • If you are choosing any read count limit, then the update count can only be less than or equal to the read count limit.
  • Read and update are independent operations i.e., they both are not dependent on each other.
  • If you reach the maximum updation limit, the clipboard becomes read only after that i.e., reaching the update limit DOES NOT automatically trigger deletion of the clipboard.
  • If you make wrong password attempts while trying to update the contents of the clipboard, then that is also counted as wrong password attempts.
    NOTE: For example, you know the contents of the clipboard that you generated. You don't want to read it but just you need to update it. Then you can enter the clipboard ID, password and the updated text and press the Update Text button. In that case if password is found to be wrong, then it is also counted as a wrong password attempt.
  • If you want the system to recommend the TTL, maximum read count, maximum wrong password attempt count and maximum update count you can do that by clciking on the Generate Recommendations button.
    Note that the recommendation generated may not always be accurate because its a heuristic based recommendation, i.e., its only based on the words that you want to send as a message. It uses only predefined set of rules and pattern matching for giving this recommendation. For giving this recommendation your data is not sent to any server.
    Also for giving this recommendation, no Artificial Intelligence(AI) or Machine Learning(ML) models are used.
  • If you want to delete the clipboard instantly at any point of time, you can go to the Revoke Tab, then enter the Clipboard ID, Password and the revoke ID of the clipboard that you need to delete.
    NOTE: If you make a wrong password attempt while triggering instant deletion, it would NOT be counted as a wrong password attempt.
