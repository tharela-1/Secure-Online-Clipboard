How to use this website?
  • Step - 1: Type the text that you need to send to the receiver
  • Step - 2: Type the password for the message
  • Step - 3: Set the Time To Live(TTL) value i.e., for how long the message should be accessible
    For example:
    1. If you need to set the time as 12 hours 31 minutes 58 seconds then enter the following values: 12 in the hours box 31 in the minutes box and 58 in the seconds box.
    2. If you need to set the time as 12 hours then enter the following values: 12 in the hours box and 0 in the minutes box and 0 in the seconds box
    3. If you need to set the time as 11 hours 45 minutes then enter the following values: 11 in the hours box 45 in the minutes box and 0 in the seconds box
    4. If you need to set the time as 11 hours 45 seconds then enter the following values: 11 in the hours box 0 in the minutes box and 45 in the seconds box
    5. If you need to set the time as 25 minutes 45 seconds then enter the following values: 0 in the hours box 25 in the minutes box and 45 in the seconds box
    6. If you need to set the time as 35 minutes then enter the following values: 0 in the hours box 35 in the minutes box and 0 in the seconds box
    7. If you need to set the time as 45 seconds then enter the following values: 0 in the hours box 0 in the minutes box and 45 in the seconds box
  • If you want to opt for the extra privacy features, you can do that as well by doing the following:
    • If you want to create a restriction to access the clipboard contents only for a specific number of times then you can enter that value in the input field otherwise enter 0.
    • If you want to delete the record in the database after specific number of wrong password attempts then enter that value in the input field otherwise enter 0.
  • Step - 4: Press the Send Text button
  • Step - 5: Note down the clipboard code generated and password that you have entered, because those data are very important for retrieval of text.
  • Step - 6: To retrieve the text, enter the clipboard ID and the password and press the Retrieve Text button.
  • Step - 7: You will see the retrieved text in the text area.
Points to note:
  • To reset the form you an press the reset button in the respective section to reset that particular section.
  • If the clipboard ID or password is lost, there is no way of retrieving that.
  • You can send feedback to the developer by clicking the Send Feedback button in the Home Page. It would take you to the Feedback page where you can enter the feedback.
  • Ensure that you have filled all the required fields in the Section - I and Section - II of the Sender Section before you press the Send Text button.
  • If you press the Show Password button then the text of the button changes from Show Password to See Now and you can see the password that you have typed for 5.5 seconds. During the view time, you can't edit the password that you have entered in the password field. After that the text of the button changes back to Show Password. Then you can edit the password that you have entered in the password field. When the text of the button in the sender section's password field has the text Show Password at that time you can type / edit the password entered in the password field in the sender section. When the text of the button in the sender section's password field is See Now, you can't edit the password that you have entered in the password field in the sender section.
  • If you press the Show Password button then the text of the button changes from Show Password to See Now and you can see the password that you have typed for 5.5 seconds. During the view time, you can't edit the password that you have entered in the password field. After that the text of the button changes back to Show Password. Then you can edit the password that you have entered in the password field. When the text of the button in the receiver section's password field has the text Show Password at that time you can type / edit the password entered in the password field in the receiver section. When the text of the button in the receiver section's password field is See Now, you can't edit the password that you have entered in the password field in the receiver section.
