How to use this website?
  • Step - 1: Type the text that you need to send to the receiver
  • Step - 2: Type the password for the message
  • Step - 3: Set the Time To Live(TTL) value i.e., for how long the message should be accessible
  • If you want to opt for the extra privacy features, you can do that as well by doing the following:
    • If you want to create a restriction to access the cipboard contents only for a specific number of times then you can enter that value in the input field otherwise enter 0.
    • If you want to delete the record in the database after specific number of wrong password attempts then enter that value in the input field otherwise enter 0.
  • Step - 4: Press the Send Text button
  • Step - 5: Note down the clipboard code generated and password that you have entered, because those data are very important for retrieval of text.
  • Step - 6: To retrieve the text, enter the clipboard ID and the password and press the Retrieve Text button.
  • Step - 7: You will see the retrieved text in the text area.
Points to note:
  • To reset the form you an press the reset button in the respective section to reset that particular section.
  • If the clipboard ID or password is lost, there is no way of retrieving that.
  • You can send feedback to the developer by clicking the Send Feedback button in the Home Page. It would take you to the Feedback page where you can enter the feedback.
